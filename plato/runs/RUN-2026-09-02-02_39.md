## Findings

1. **compose-secrets-warning** — every `docker compose run` printed
   `level=warning msg="secrets uid, gid and mode are not supported, they will be ignored"`.
   Docker Compose on this host (OrbStack, Engine 29.4.0) ignores the long-syntax
   uid/gid/mode attributes on the compose file's `secrets:` entries. Cosmetic for this
   runbook — the key still mounts, every suite passed — but the compose file's portability
   claim now carries this wart on the second host.
