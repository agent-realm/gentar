# d2-tweaker drill — bending the emitted demo-subject scaffold

In character: staged `plato/scaffold/demo-subject/` as a real git checkout
under `/tmp/gentar-s3-b1-d2-tweaker/subjects-root/`, emitted the scaffold via
`coordinator subject init demo-subject --repo https://github.com/x/demo --dir
/out/scaffold`, then bent the emitted TOML my way across six rounds, rerunning
after each:

1. **bend 1 (half-fill + rename)** — filled `path` and `command`, commented
   `contains` in files (as emitted), renamed commands' `contains` to
   `substring = "installed"` on a command whose output lacks "installed".
   Result: green, 2/2, exit 0 — the substring intent silently dropped.
   (finding: silent-ignore)
2. **bend 2 (stray trailing comma)** — `substring = "installed",` → raw
   TOMLDecodeError traceback on `run` AND on `ls`, exit 1 both.
   (finding: cryptic-bend-error)
3. **bend 3 (comment the probes out)** — both verify blocks commented →
   `oracle ok: 0/0 assertions passed`, exit 0, passing report.
   (finding: fake-green, vacuous)
4. **bend 4 (quotes for brackets)** — `steps = '...'` instead of an array →
   `oracle step 0 failed rc=127: c`, exit 1. (finding: cryptic-bend-error)
5. **bend 5 (empty probe table)** — `[[verify.files]]` with no keys → honest
   exit 2, `verify.files[0] missing path`. (answer, not a finding)
6. **bend 6 (stub under a renamed key)** — `substring = "TODO"` → stub guard
   silent, run proceeds, green 2/2, exit 0. (finding: fake-green, guard bypass)
