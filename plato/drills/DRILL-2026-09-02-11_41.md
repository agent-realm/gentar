# d2-abuser drill record — hostile input at every intake

Method: one hostile input per attempt, exact reaction recorded, moved
on. 40+ attempts across four intakes: `subject init`, the TOML loader
(`ls`), the run-time guards + bench (`run`), and teardown. Full raw
logs: /tmp/gentar-s4d2-scratch/{init-log.txt,init-log2.txt,loader-log.txt,run-log.txt}.

## What held (the attacks that did not land)

- **`subject init` intake is closed.** Shell metacharacters, `$()`,
  backticks, `../../` traversal, `..`, unicode, embedded newline, empty
  name — all exit 2 with the name quoted back. 300-char and 65-char
  names refused with the cap named; 64 accepted. `--repo` newline
  (header-injection attempt), empty, whitespace — exit 2. `--dir` at an
  existing file, at an un-creatable path under a file — clean exit 2
  naming the path. No write outside the dir via the name: it is
  regex-pinned to one path segment, so no traversal filename exists.
- **No silent overwrite.** Second emit without `--force` refuses naming
  BOTH files (`--dir already holds scaffold output: …`); a partial
  state (only the toml present) refuses naming just that file; an
  unrelated `keepme.txt` in the dir is untouched by both emit and
  `--force`.
- **Loader strictness held where s3 broke.** Renamed probe key
  (`substring =`), off-type `verify = "boom"`, `steps = 5`, budget

## Findings (named above, in order hit)

1. **loader-recursion-traceback** — first traceback of the day. The
   s4 mechanism says "config errors are exit 2, never tracebacks";
   tomllib's RecursionError is neither a TOMLDecodeError nor anything
   else caught in cli.main, so a 10k-deep array in any scenarios-dir
   file turns `ls` and `run` into exit-1 tracebacks.
2. **loader-isdir-traceback** — my character's "files that are
   directories": `open()` on a directory raises OSError, not
   TOMLDecodeError; same escape from the exit-2 net.
3. **vacuous-driver-green** — the assert guard's driver exemption has
   no floor. A driver suite that drives nothing (`command` runs, zero
   turns, zero probes) gets a real bench, a PASS report with no
   Assertions section, and exit 0. This is the fake-green shape s4 set
   out to kill, entered through the driver door instead of the
   verify-deleted door.
4. **budget-guard-blind-to-spend** — the guard consults only the
   declared ceiling, never the spend. tokens=0 (what the scaffold
   emits!) + any simulate_spend is invisible to the cap; negative
   values are accepted everywhere (loader, guard arithmetic, ledger
   record). The budget-sim suite's own pass/pass/refuse contract holds
   only while every scenario declares a positive tokens.
5. **subject-init-symlink-escape** — `--force` consent is to
   overwrite "scaffold output", but write_text follows symlinks, so
   the bytes can land anywhere a pre-planted link points. Requires
   --force AND prior control of a path inside the target dir — I
   report the conditions with the event; the pilot can judge how much
   that is worth in a subject repo.

## Observations (not report-worthy; recorded for the pilot)

- `credentials = "STRING"` (bare, not a list) loads — `list("X")`
  makes every character a credential name; the guard then over-refuses
  with a silly message. Honesty unaffected (refusal, never green).
- `subject = "../../etc"` loads and RUNS GREEN: delivery tars
  `/subjects/../../etc` — the coordinator container's /etc — into the
  sandbox workspace. No refusal, no traceback, sandbox-scoped. The
  subjects-root boundary is a string join, not a check.
- Probe `"TODO "` (trailing space) evades the stub guard's exact
  match — but the run lands honest RED (exit 127 on the missing TODO
  binary), so no fake-green.
- A TOML claiming `name = "smoke"` silently loses to the builtin in
  `run` (REGISTRY checked first) and is deduped by `ls`. Confusing
  first contact, not dishonest.
- Unknown TOP-LEVEL tables (`[evil]`) are silently ignored — strict
  key-checking covers the five known tables only. A zero-probe suite
  still trips the assert guard, so this cannot fake-green alone.
- Step output flows verbatim into reports/spans (tailed). A scenario
  whose steps `echo` a credential value would put that value in the
  report; the harness itself never writes values. Not my category to
  grade — recording that the seam exists.
